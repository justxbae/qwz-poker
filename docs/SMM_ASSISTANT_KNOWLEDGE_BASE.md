Назначение: учебник и рабочая база для человека, который помогает с Telegram-каналом, медиа, исследованиями, контентом, первыми рекламными гипотезами и продвижением Weez Poker.  
Цель документа: дать помощнику контекст проекта, язык индустрии, основные определения, правила работы, первые микро-задачи и направление мышления.

## 0. Что такое Weez Poker

Weez Poker — Telegram Mini App poker room.

Продуктовая суть:

1. Человек открывает Telegram.
2. Заходит в mini app.
3. Может бесплатно попробовать rating mode на play chips.
4. Может играть cash-столы и турниры, если проект находится в режиме real-money и все платежи/выводы включены.
5. Всё происходит внутри Telegram без скачивания отдельного приложения.

Главная сила проекта для маркетинга:

> Быстрый вход + бесплатная проба + Telegram-native формат.

Главная проблема проекта для маркетинга:

> Если за столами пусто, новый игрок может уйти, даже если продукт ему интересен.

Поэтому задача SMM — не просто делать посты, а приводить людей в конкретные игровые окна, формировать доверие и создавать ощущение живого poker room.

## 1. Как нужно мыслить в этом проекте

Помощник должен мыслить не “постами”, а “движением пользователя”.

Правильная цепочка:

```
человек увидел проект
→ понял, что это poker room в Telegram
→ перешёл в бот
→ попробовал бесплатно
→ сыграл первую раздачу
→ вернулся завтра
→ увидел живое комьюнити
→ привёл друга / сделал депозит / зашёл на турнир
```

Если задача не помогает этой цепочке, она второстепенная.

Пример:

- “Сделать красивую картинку” — не цель.
- “Сделать картинку, по которой человек поймёт, что можно бесплатно зайти и сыграть в Telegram за 20 секунд” — цель.

## 2. Базовые определения SMM и маркетинга

### 2.1. SMM

SMM — Social Media Marketing. Работа с соцсетями и медиа: контент, каналы, комьюнити, реакции, комментарии, охваты, переходы, доверие.

В Weez Poker SMM отвечает за:

1. Telegram-канал.
2. Telegram-чат.
3. Посты.
4. Stories/short updates.
5. Комьюнити.
6. Поиск каналов и инфлюенсеров.
7. Оффлайн-гипотезы.
8. Сбор обратной связи.
9. Объяснение продукта.

### 2.2. Маркетинг

Маркетинг шире SMM. Это всё, что помогает пользователю:

1. узнать о продукте;
2. понять ценность;
3. начать использовать;
4. вернуться;
5. доверять;
6. платить;
7. советовать другим.

### 2.3. Воронка

Воронка — путь пользователя от первого касания до нужного действия.

Для Weez Poker:

| Этап | Что это |
|---|---|
| Reach | человек увидел пост/листовку/рекомендацию |
| Click | перешёл по ссылке |
| Bot start | открыл бота |
| First open | открыл mini app |
| Activation | сыграл первую раздачу |
| Retention | вернулся позже |
| Monetization | сделал депозит / сыграл cash / турнир |
| Referral | пригласил другого |

### 2.4. Activation

Activation — момент, когда пользователь впервые понял ценность продукта.

Для Weez Poker activation = первая сыгранная раздача, лучше в rating mode.

Просто открыть бот — не activation.

### 2.5. Retention

Retention — возвращаемость.

Примеры:

- D1 retention — сколько пользователей вернулось на следующий день.
- D7 retention — сколько вернулось через 7 дней.

Для poker room retention важнее подписчиков. Если человек один раз зашёл и ушёл — это слабый пользователь.

### 2.6. Liquidity

Liquidity — ликвидность игры. В покере это наличие игроков за столами.

Если за столом нет людей, продукт выглядит мёртвым. Даже хороший интерфейс не спасёт.

Цель SMM — помогать создавать ликвидность:

1. игровые вечера;
2. турниры;
3. rating sessions;
4. scheduled events;
5. напоминания в канал/чат;
6. активные тестеры.

### 2.7. CTA

CTA — Call To Action, призыв к действию.

Примеры CTA:

1. “Открыть бота”.
2. “Получить daily bonus”.
3. “Сыграть первую раздачу”.
4. “Зайти сегодня в 20:00”.
5. “Написать баг в support”.

Плохой пост без CTA: человек прочитал и ничего не сделал.

### 2.8. Organic traffic

Organic traffic — бесплатный трафик: посты, рекомендации, чаты, репосты, комментарии, сарафанка, SEO, TikTok/shorts без рекламы.

### 2.9. Paid traffic

Paid traffic — платный трафик: реклама в каналах, интеграции, блогеры, баннеры, оффлайн-раздача листовок.

### 2.10. Influencer

Инфлюенсер — человек или канал, у которого есть аудитория.

Для Weez Poker интересны:

1. покерные каналы;
2. карточные игры;
3. Telegram mini apps;
4. crypto audience;
5. gaming audience;
6. локальные городские сообщества 18+;
7. микроинфлюенсеры, где аудитория реально доверяет автору.

## 3. Метрики и аббревиатуры

### 3.1. Reach

Reach — охват. Сколько людей увидело пост.

### 3.2. Views

Views — просмотры. В Telegram чаще смотрим именно views поста.

### 3.3. CTR

CTR = Click Through Rate.

Формула:

```
CTR = clicks / views * 100%
```

Пример:

```
1000 views
20 clicks
CTR = 20 / 1000 * 100% = 2%
```

Для Telegram-постов на старте:

| CTR | Оценка |
|---:|---|
| 0.3–0.5% | слабо |
| 1–2% | нормально |
| 3%+ | хорошо |

### 3.4. CPM

CPM = Cost Per Mille, цена за 1000 просмотров.

Формула:

```
CPM = price / views * 1000
```

Пример:

```
пост стоит $20
получил 5000 views
CPM = 20 / 5000 * 1000 = $4
```

### 3.5. CPC

CPC = Cost Per Click.

```
CPC = price / clicks
```

### 3.6. CPA

CPA = Cost Per Action.

Для Weez Poker лучше считать несколько CPA:

1. CPA bot start.
2. CPA first game.
3. CPA active user.
4. CPA depositor.

Пример:

```
размещение стоит $20
получили 10 first games
CPA first game = $2
```

### 3.7. CAC

CAC = Customer Acquisition Cost. Стоимость привлечения пользователя.

Для раннего проекта лучше считать не только depositor CAC, но и active user CAC.

### 3.8. LTV

LTV = Lifetime Value. Сколько проект потенциально зарабатывает с пользователя за всё время.

В poker room LTV может формироваться через:

1. rake;
2. tournament fee;
3. повторные депозиты;
4. долгую активность.

На раннем этапе LTV точно неизвестен, поэтому нельзя обещать партнёрам завышенные цифры.

### 3.9. ROI / ROAS

ROI — окупаемость вложений.

ROAS — revenue from ads / ad spend.

Для early-stage Weez Poker важнее не только ROAS, а:

1. сколько людей дошло до игры;
2. сколько вернулось;
3. сколько создало ликвидность;
4. сколько багов нашли;
5. сколько доверия появилось.

### 3.10. DAU / WAU / MAU

| Аббревиатура | Значение |
|---|---|
| DAU | Daily Active Users |
| WAU | Weekly Active Users |
| MAU | Monthly Active Users |

Для Weez Poker на старте основная метрика — WAU.

### 3.11. Churn

Churn — отток пользователей. Люди, которые пришли и перестали играть.

Основные причины churn в покере:

1. пустые столы;
2. непонятно, как начать;
3. нет доверия к деньгам;
4. неудобный интерфейс;
5. долго ждать соперника;
6. баги;
7. нет события/мотива вернуться.

### 3.12. Cohort

Cohort — группа пользователей, пришедших в один период или из одного источника.

Пример:

1. cohort “листовки 10 июля”;
2. cohort “пост в канале X”;
3. cohort “друзья тестера Y”.

Когорты нужны, чтобы понимать, какой источник приводит нормальных игроков.

## 4. Основные определения poker/iGaming

### 4.1. iGaming

iGaming — индустрия онлайн-игр на деньги: poker, casino, betting, fantasy sports и другие форматы.

Weez Poker ближе к online poker room, а не к casino.

### 4.2. Poker room

Poker room — платформа, где игроки играют друг против друга, а проект зарабатывает обычно на комиссии/rake/fee.

Важно: в покере проект не играет против пользователя, в отличие от казино. Игроки играют между собой.

### 4.3. Rake

Rake — комиссия poker room с банка раздачи.

Пример:

```
банк $10
rake 5%
комиссия = $0.50
```

В нормальном poker room обычно есть cap — максимальный rake с одной раздачи.

### 4.4. WCR / Weighted Contributed Rake

WCR — модель распределения рейка по игрокам пропорционально их вкладу в банк.

Пример:

```
Игрок A вложил $8
Игрок B вложил $2
Банк $10
Rake $0.50

A contributed 80% → rake share $0.40
B contributed 20% → rake share $0.10
```

WCR важен для affiliate/referral, потому что партнёру логичнее платить процент не от депозитов, а от реального contributed rake его игроков.

### 4.5. Cash game

Cash game — игра на реальный баланс. Игрок садится за стол с buy-in, может выйти и забрать стек по правилам стола.

### 4.6. Rating mode

Rating mode — бесплатный режим на play chips.

В Weez Poker:

1. это не деньги;
2. нельзя вывести;
3. нельзя смешивать с cash;
4. нужен для бесплатной пробы, активности и leaderboard.

### 4.7. Play chips

Play chips — фишки бесплатного режима.

Важно: это не валюта и не деньги.

### 4.8. Daily bonus

Daily bonus — ежедневная выдача play chips.

В Weez Poker: 35 000 play chips раз в 24 часа.

Маркетинговый смысл:

1. повод вернуться каждый день;
2. free trial loop;
3. мягкая привычка заходить в продукт.

### 4.9. Tournament

Tournament — турнир. Игрок платит buy-in/fee или получает ticket/freeroll entry, играет до вылета или победы.

### 4.10. Freeroll

Freeroll — турнир без платного buy-in, но с призом.

Для early-stage проекта freeroll полезен как:

1. событие;
2. причина зайти в конкретное время;
3. награда для активных;
4. способ оживить канал.

### 4.11. SNG

SNG = Sit and Go. Турнир стартует, когда набралось нужное количество игроков.

### 4.12. MTT

MTT = Multi Table Tournament. Турнир на много столов, обычно стартует по расписанию.

### 4.13. Leaderboard

Leaderboard — таблица лидеров.

В Weez Poker можно использовать:

1. rating leaderboard;
2. weekly leaderboard;
3. tournament leaderboard;
4. tester leaderboard;
5. bug hunter leaderboard.

### 4.14. Responsible gaming

Responsible gaming — ответственная игра.

В публичной коммуникации обязательно:

1. 18+;
2. не обещать заработок;
3. не давить на проигравших;
4. не использовать “отыграйся”;
5. не призывать играть на последние деньги.

## 5. Важные ограничения рекламы iGaming

Помощник должен понимать: нельзя продвигать Weez Poker как обычную игру без ограничений.

### 5.1. Telegram Ads

Официальные правила Telegram Ads запрещают рекламу gambling/casino activity involving real money, prizes or goods of value. Источник:  
https://ads.telegram.org/guidelines

Вывод:

- официальный Telegram Ads для прямой real-money рекламы не является базовым каналом;
- в Telegram лучше использовать органику, комьюнити, договорённости с каналами, аккуратные формулировки, early access, poker education.

### 5.2. Meta

Meta разрешает online gambling/gaming ads только с предварительным разрешением и соблюдением законов. Источник:  
https://transparency.meta.com/policies/ad-standards/restricted-goods-services/gambling-games/

### 5.3. Google Ads

Google требует соблюдения local laws и сертификацию gambling ads. Источник:  
https://support.google.com/adspolicy/answer/15132179

### 5.4. TikTok

TikTok допускает gambling ads только в определённых рынках, где это законно и при выполнении требований. Источник:  
https://ads.tiktok.com/help/article/tiktok-ads-policy-gambling-and-games

### 5.5. Практический вывод

На раннем этапе Weez Poker нельзя строить на агрессивной платной рекламе “игра на деньги”.

Безопаснее развивать:

1. free rating mode;
2. Telegram-native poker product;
3. раннее комьюнити;
4. образовательный poker content;
5. bug hunt;
6. events/freerolls;
7. партнёрства вручную;
8. локальные оффлайн-активации 18+.

## 14. Как писать пост

Структура хорошего поста:

1. Hook — первая строка.
2. Context — что это.
3. Value — почему человеку важно.
4. Action — что сделать.

Пример:

```
Покер прямо внутри Telegram.

Weez Poker — mini app, где можно зайти и сыграть без скачивания отдельного приложения.
Для пробы есть бесплатный rating mode и daily bonus 35 000 фишек.

Открой бота и сыграй первую раздачу.
18+.
```

### Плохие признаки поста

1. Нет понятного CTA.
2. Слишком много текста.
3. Неясно, что за проект.
4. Обещает деньги.
5. Нет 18+ там, где нужен.
6. Слишком похоже на казино-скам.
7. Не объясняет free trial.

## 15. Как предлагать гипотезы

Помощник должен не просто выполнять, а думать.

Формат гипотезы:

```
Гипотеза:
Почему это может сработать:
Что нужно сделать:
Сколько времени:
Какая метрика успеха:
Риски:
Что делать, если сработает:
Что делать, если не сработает:
```

Пример:

```
Гипотеза:
Если сделать “Rating вечер” в пятницу 20:00–22:00 и заранее напомнить 3 раза, мы получим больше первых игр, потому что люди зайдут одновременно.

Метрика успеха:
20+ открытий бота, 8+ first games, 50+ rating hands.
```

## 16. Вектор для самостоятельных идей

Помощник может предлагать модели развития, если они отвечают хотя бы одному критерию:

1. увеличивают first game;
2. увеличивают retention;
3. создают ликвидность за столами;
4. повышают доверие;
5. приводят партнёров;
6. дают качественный feedback;
7. помогают объяснить продукт;
8. снижают страх перед первым входом.

### Примеры направлений для размышлений

1. “Rating evenings” — игровые окна.
2. “Bug hunt” — поиск багов с таблицей и наградами.
3. “Founder players” — статус ранних игроков.
4. “Weekly leaderboard” — причина вернуться.
5. “Poker school в канале” — обучение новичков.
6. “Freeroll for active players” — событие для удержания.
7. “Offline QR testing” — локальная проверка спроса.
8. “Streamer table” — игра с конкретным человеком в конкретное время.
9. “Invite 2 friends rating night” — мягкая рефералка без cash-pressure.
10. “Hand of the week” — контент из раздач.

## 17. Что помощник не должен делать сам

Без согласования нельзя:

1. обещать деньги/доход;
2. запускать платную рекламу;
3. писать от имени проекта условия выплат;
4. менять правила affiliate/referral;
5. обещать бонусы;
6. публиковать финансовые данные игроков;
7. публиковать спорные юридические формулировки;
8. общаться с крупными партнёрами без согласования;
9. писать “официально разрешено”, если нет подтверждения;
10. делать агрессивную gambling-рекламу.

## 21. Минимальные рабочие стандарты

Помощник должен:

1. не терять ссылки;
2. вести таблицы аккуратно;
3. писать коротко и понятно;
4. не придумывать условия проекта;
5. отделять факты от мнений;
6. показывать примеры;
7. считать базовые метрики;
8. предлагать гипотезы;
9. фиксировать результаты;
10. не бояться писать “не знаю, нужно уточнить”.
