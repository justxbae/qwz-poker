# Weez Poker — атрибуция трафика и отчётность

## Простое объяснение

Атрибуция отвечает на вопрос: «Из какого конкретного объявления пришёл этот игрок и дошёл ли
он до игры/депозита?» Без неё нельзя понять, что масштабировать, даже если реклама бесплатная.

## Формат Telegram-ссылки

```text
https://t.me/weezpokerbot/app?startapp=source--campaign--creative--placement
```

Примеры:

```text
telegram--beta_august--channel_post_01--button
tiktok--organic_august--video_07--bio
offline--chelyabinsk--flyer_kirovka_a--qr
ref_partnerivan
```

Значения:

- `source` — площадка: telegram, tiktok, offline, youtube;
- `campaign` — общая активность/период;
- `creative` — конкретный пост, ролик или макет;
- `placement` — место ссылки: button, bio, qr, description;
- `ref_<code>` — отдельная партнёрская ссылка;
- `tbl_<token>` — приглашение за стол, не маркетинговая кампания.

Сервер уже хранит first touch и last touch. Повторный прямой вход не стирает источник.

## Правила именования

- только латиница, цифры, `_` и `-`;
- один смысл — одно стабильное имя;
- нельзя повторно использовать creative id для другого макета;
- QR каждого офлайн-макета уникален;
- тестовые ссылки начинаются с campaign `internal_test` и исключаются из продуктового отчёта.

## Минимальная воронка

```text
Новые пользователи → открыли Mini App → сели за стол → завершили первую руку → вернулись → FTD
```

Формулы:

```text
Activation = завершили первую руку / новые пользователи
Table join = сели за стол / открыли Mini App
FTD       = первые плательщики / новые пользователи
D1 return = вернулись на следующий день / активированные
CAC       = расход / активированные (обязательно указывать знаменатель)
```

## Автоматическая сводка владельцу

Раз в день бот сообщает: уникальные открытия, игроков за столами, завершённые руки, cash rake,
депозиты, выводы, текущую посадку и ведущий источник. Время регулируется
`ADMIN_DAILY_REPORT_HOUR`, по умолчанию 21:00 Asia/Yekaterinburg. Повтор после рестарта не
отправляется, если отчёт за этот календарный день уже записан в `admin_events`.
