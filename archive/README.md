# Архив Weez Poker

Единая папка для устаревших, отложенных и требующих пересмотра материалов.
Файлы сохранены; ссылки на перемещённые исходники обновлены.
Актуальная точка входа — [README проекта](../README.md).

| Каталог | Содержимое и причина переноса |
| --- | --- |
| `assets/` | Прежний демонстрационный знак приложения `app-icon-v1.svg` |
| `design/` | Старые дизайнерские ТЗ, UI Kit и исходники `figma/`; не загружаются приложением |
| `planning/` | Инструкции для прежних чатов, большие enterprise/beta-ТЗ и июльский roadmap; нуждаются в перепроверке |
| `contracts/` | Старые дополнительные описания экономики и fairness; основной `MASTER_SPEC.md` сохранён в корне |
| `audits/` | Предыдущие отчёты и первый этап уборки |
| `marketing/` | SMM, партнёрка и инструкции Telegram-канала, отложенные до готовности продукта |
| `business/` | Расчётные сценарии и старые операционные таблицы |
| `research/` | Датированное исследование рынка и PDF |
| `exports/` | Прежние PDF-экспорты |
| `vendor/` | Исходные Mocha-тесты, README, package metadata и Bower-манифест сторонней библиотеки |

Наличие материала в архиве не означает, что он неверен целиком. Это справочный
источник, а не актуальный план или доказательство выполненной работы. Старые
числа, статусы, ссылки на чаты и команды необходимо проверять перед использованием.

Используемые приложением изображения сохранены в `public/assets/`.
Личные локальные документы находятся в игнорируемой `.local/` и не предназначены
для удаления вместе с временными файлами. Секреты и `.env` в архив не переносились.
