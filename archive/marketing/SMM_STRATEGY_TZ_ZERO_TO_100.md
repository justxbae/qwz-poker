# Weez Poker — большое ТЗ по SMM/маркетингу от 0 до 100 активных пользователей

Дата: 2026-07-08  
Статус: рабочий документ для стратегии, постановки задач напарнику и дальнейшего дробления на микро-ТЗ.  
Главная цель: построить SMM/маркетинговую систему, которая не просто “ведёт канал”, а приводит игроков, доводит их до первой игры, удерживает и помогает столам быть живыми.

---

## 0. Как мыслит сильный SMM-стратег для нулевого проекта

Сильный SMM-специалист не начинает с вопроса “что сегодня запостить”. Он начинает с воронки и ликвидности.

Для Weez Poker главная проблема не в том, чтобы набрать подписчиков. Главная проблема — чтобы новый человек:

1. понял за 5–10 секунд, что это poker room внутри Telegram;
2. смог бесплатно попробовать rating mode;
3. увидел, что проект живой;
4. сделал первую игру;
5. вернулся;
6. позже попробовал cash или турнир;
7. привёл кого-то ещё.

Поэтому SMM должен мыслить не контентом, а цепочкой:

```
контакт с проектом
→ переход в бот
→ первая бесплатная игра
→ повторный заход
→ доверие
→ депозит / турнир / cash game
→ удержание
→ реферал / партнёр / контент от игрока
```

Если посты не двигают пользователя по этой цепочке — это шум.

## 1. Ограничения и правила безопасности

Проект связан с poker/iGaming, поэтому маркетинг нельзя строить как обычный Telegram-стартап.

### 1.1. Что нельзя использовать в публичных материалах

Запрещённые или рискованные формулировки:

1. “Гарантированный заработок”.
2. “Лёгкие деньги”.
3. “Заработай на покере сегодня”.
4. “100% выигрыш”.

6. “Обойди казино”.
7. “Без риска”.
8. “Деньги всем”.
9. “Играй на последние”.
10. Контент, нацеленный на несовершеннолетних.

### 1.2. Что можно использовать

Разрешённый безопасный вектор:

1. “Poker room внутри Telegram”.
2. “Быстрый вход без скачивания приложения”.
3. “Бесплатный rating mode для пробы”.

### 1.3. Рекламные политики платформ

Перед платным продвижением обязательно учитывать:

1. Telegram Ads запрещает рекламу gambling/casino activity involving real money/prizes в официальной политике:  
   https://ads.telegram.org/guidelines
2. Meta допускает online gambling/gaming ads только с авторизацией и соблюдением законов:  
   https://transparency.meta.com/policies/ad-standards/restricted-goods-services/gambling-games/
3. Google Ads требует сертификацию для gambling/social casino и работает по country-specific rules:  
   https://support.google.com/adspolicy/answer/15132179
4. TikTok ограничивает gambling/games of chance и допускает social casino только в отдельных условиях/рынках:  
   https://ads.tiktok.com/help/article/update-to-social-casinos-june-2026

Вывод: на старте не строить стратегию на прямой платной рекламе “реальные деньги / казино / гемблинг”. Основной упор: органика, комьюнити, партнёрства, покерное обучение, оффлайн-точки, рефералы, ранний доступ.

## 3. Что считаем активным пользователем

Нельзя считать активным просто подписчика канала или человека, который открыл бот.

### 3.1. Active user / WAU

Активный пользователь недели — пользователь, который за последние 7 дней сделал минимум одно:

1. сыграл 20+ rating hands;
2. сыграл 5+ cash hands;
3. зарегистрировался в турнире;
4. сделал депозит;
5. пригласил qualified referral;
6. отправил полезный bug report после реального теста.

### 3.2. Цель “100 активных”

100 активных — это не 100 подписчиков. Это примерно:

| Сегмент | Кол-во | Роль |
|---|---:|---|
| Rating-only players | 55–65 | создают жизнь, тестируют UX, возвращаются за daily bonus |
| Cash-curious users | 20–25 | пробуют кассу, смотрят столы, делают маленькие депозиты |
| Cash regulars | 8–12 | создают реальную игровую ликвидность |
| Tournament users | 10–20 | заходят под события |
| Testers/ambassadors | 5–10 | помогают искать баги и приводить первых людей |

Главная бизнес-цель до 100 активных — не прибыль, а ликвидность и доверие.

Это главный показатель для poker room:

| Метрика | Почему важна |

| Time to second player | сколько человек ждёт соперника |
| Hands/hour | реальная активность |
| Rating hands/day | бесплатная игровая активность |
| Cash hands/day | реальная монетизация |

## Этап 3 — 30–60 активных

Срок: 4–8 недель.  
Цель: начать системное привлечение через партнёров и контент.

### Основные действия

1. Найти 50–100 Telegram-каналов/чатов/микроинфлюенсеров.
2. Оценить их по таблице.
3. Провести 10–20 тестовых размещений или договорённостей.
4. Запустить реферальный акцент без агрессивных обещаний.
5. Запустить weekly leaderboard и публичную статистику проекта.

### Таблица оценки канала/инфлюенсера

| Поле | Что писать |
|---|---|
| Название |
| Ссылка |
| Тематика |
| Подписчики |
| Средний охват поста |
| ER = views/subscribers |
| Цена |
| CPM = цена / views * 1000 |
| Есть ли покерная аудитория |
| Есть ли боты/накрутка |
| Риски |
| Формат размещения |
| Итоговый score 1–10 |

### Формула оценки

```
CPM = price / average_views * 1000
Expected clicks = average_views * CTR
Expected starts = Expected clicks * bot_start_rate
Expected active = Expected starts * first_game_rate * D1_retention
Expected CPA active = price / Expected active
```

Базовые предположения для раннего теста:

| Параметр | Осторожно | Нормально | Хорошо |
|---|---:|---:|---:|
| CTR из поста | 0.5% | 1.5% | 3% |
| Bot start / click | 40% | 60% | 75% |
| First game / start | 30% | 50% | 70% |
| D1 retention | 15% | 25% | 40% |

Пример расчёта:

```
канал: 5 000 views
цена: $20
CTR: 1.5% = 75 clicks
bot start: 60% = 45 starts
first game: 50% = 22.5 players
D1: 25% = 5.6 retained active
CPA active = $20 / 5.6 = $3.57
```

Если CPA active выше $5–7 на раннем этапе, размещение спорное, если нет сильного брендингового эффекта.

## 10. Задачи для напарника

Напарник не обязан быть маркетологом. Его зона — сбор данных, подготовка контента, контроль таблиц и простые публикации.

### 10.1. Ежедневные задачи

1. Проверить Telegram-каналы конкурентов.
2. Выписать 5 идей постов.
3. Найти 5 потенциальных каналов/чатов для размещения.
4. Обновить таблицу каналов.
5. Подготовить 1 короткий пост или черновик.
6. Собрать обратную связь от игроков/тестеров.
7. Записать баги/жалобы/вопросы в таблицу.

### 10.2. Еженедельные задачи

1. Найти 30–50 новых каналов/чатов/инфлюенсеров.
2. Посчитать CPM/CPA-гипотезу.
3. Подготовить 5–7 постов на неделю.
4. Собрать weekly report:
   - сколько постов;
   - сколько просмотров;
   - сколько переходов;
   - сколько starts;
   - сколько first games;
   - сколько активных;
   - что сработало;
   - что не сработало.
5. Подготовить список гипотез на следующую неделю.

### 10.3. Что он должен изучать

1. Telegram-каналы poker/iGaming/crypto/gaming.
2. Как конкуренты оформляют посты.
3. Какие заголовки собирают охваты.
4. Какие механики удержания используют.
5. Какие акции выглядят безопасно, а какие выглядят как скам.
6. Где аудитория реально пишет комментарии.
7. Какие каналы накручены.

## 13. Оффлайн-маркетинг

Оффлайн можно тестировать, но не как главный канал. Он полезен для первых касаний и локального комьюнити.

### 13.1. Где тестировать

Для Челябинска логика такая:

1. места с молодёжным/студенческим трафиком;
2. кофейни/антикафе/настольные игры;
3. локальные оффлайн-покерные игры без real-money фокуса;
4. кибер/игровые пространства;
5. бары/лаунжи только если формат 18+ и без агрессивной gambling-подачи.

### 13.2. Формат листовки

Не продавать “деньги”. Продавать “быстрый poker room в Telegram”.

Пример:

```
Poker room внутри Telegram

Без скачивания приложения.
Бесплатный rating mode.
Daily bonus 35 000 фишек.

Открой Weez Poker:
[QR]

18+. Играйте ответственно.
```

### 13.3. Расчёт эффективности листовок

Осторожный сценарий на 1000 листовок:

| Этап | Конверсия | Результат |
|---|---:|---:|
| Получили листовку | 1000 | 1000 |
| Отсканировали QR | 1% | 10 |
| Открыли бот | 60% | 6 |
| Сыграли первую игру | 50% | 3 |
| Вернулись D1 | 30% | 1 |

Хороший сценарий:

| Этап | Конверсия | Результат |
|---|---:|---:|
| Получили листовку | 1000 | 1000 |
| QR scan | 3% | 30 |
| Bot open | 70% | 21 |
| First game | 60% | 13 |
| D1 | 35% | 5 |

Вывод: листовки имеют смысл только при дешёвой печати/раздаче и хорошей точке. Обязательно использовать отдельный tracking link.

## 19. Что нельзя считать успехом

1. Просто вырос канал.
2. Просто много просмотров.
3. Просто красивый дизайн постов.
4. Просто много реакций.
5. Просто люди написали “интересно”.

Успех — это когда люди дошли до игры и вернулись.

## 20. Что считать успехом

### На 2 неделе

1. 50–100 подписчиков.
2. 30–50 bot starts.
3. 10+ first games.
4. 5+ активных игроков.
5. 10+ полезных feedback/bug points.

### На 1 месяце

1. 150–300 подписчиков.
2. 20–30 активных игроков.
3. 200–500 rating hands/day в активные дни.
4. первые cash tests.
5. понятный список каналов, где есть аудитория.

### На 3 месяце

1. 700–1500 подписчиков.
2. 60–100 активных игроков/week.
3. стабильные игровые окна.
4. первые регулярные cash players.
5. weekly events/leaderboard.
6. партнёрская база.
